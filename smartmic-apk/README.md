# SmartMic Test Forms – offline Android APK v0.4

This Android build is fully offline. The PWA on Render is a separate project and is unchanged.

## What's new in v0.4
- Each minute, all entered values, checkboxes, text and image/video Blob attachments are saved by overwriting **one** IndexedDB draft record. No DOCX or PDF is generated by this timer.
- Edits are also backed up after a 700-ms pause, photos/videos are committed immediately, and switching apps triggers a best-effort backup.
- The last saved draft automatically restores when the operator reopens the app.
- Parameter checks use ✓ Dodržané or ✕ Zmenené; comments go into notes.
- Precoat is displayed before Riedenie.
- Text and media note fields are multiline and vertically resizable.
- The Kal section now has up to eight photos in addition to its videos; both camera and Gallery are supported.
- A new Dávkovanie do miešacej nádrže section follows Jar testy, with data exported into DOCX and PDF.
- Photo thumbnails are managed without leaking object URLs, and photos are resized before IndexedDB storage. A failed attachment save is reported instead of silently continuing. Bad pictures should not block the whole DOCX/PDF export.
- SAVE produces one editable DOCX and one native PDF. ZIP includes video files when present. Files stay local.

## Android installation & continuity
The app ID is `com.hofitech.smartmicforms.v04`. This APK installs **beside** v0.3 rather than overwriting its existing local data. Export important v0.3 drafts using SAVE before starting a new test in v0.4. Drafts are not automatically transferred between versions.

## Technical notes
The Android build uses bundled web assets via Capacitor 8.6.0, no external cloud API. IndexedDB and photos use Android local storage. Native document exports go into Download/SmartMic. When sufficient storage is unavailable, backup can fail and an explicit warning appears. Background Android timers may be paused; change-based saves and visibility backups mitigate that, but no mobile app can guarantee recovery if the operating system abruptly kills it before a pending transaction completes.

## Validation
GitHub Actions automatically compiles a debug APK. Before production usage verify on actual Android devices: eight consecutive photos, gallery video, video+photo under Kal, airplane mode, closed/reopened app, and both DOCX and PDF exports. Do not delete v0.3 until results are archived.
